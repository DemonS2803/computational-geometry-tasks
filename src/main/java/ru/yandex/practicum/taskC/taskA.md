Задача C. Место встречи изменить нельзя
Имя входного файла: стандартный ввод
Имя выходного файла: стандартный вывод
Ограничение по времени: 1 секунда
Ограничение по памяти: 256 мегабайт
Даны N точек. Найдите такие две из них, что расстояние между ними минимально.
Формат входных данных
Первая строка входного файла содержит целое число N (2 6 N 6 100 000) — количество точек. Каждая из следующих N строк содержит пару целых чисел X и Y , разделённых пробелом, —
координаты (−109 6 X, Y 6 109
). Все точки различны.
Формат выходных данных
Единственная строка выходного файла должна содержать координаты двух выбранных точек.
